## Role

<Lede>Core mobile team. Stabilize, speed up, and modernize a multi-banner app with global rollouts.</Lede>

- Platform: Expo and React Native, bridgeless
- Multi-banner configuration with staging and production banners
- Key features: Made-to-Order, global rollouts
- Wrote the app and brand onboarding documentation used to stand up new banners

## What I shipped

<Lede>Faster lists and storage, a modern runtime, and a CI pipeline a third of its old length.</Lede>

### Performance

- Faster local storage with MMKV
- FlashList in place of FlatList for list rendering
- Better API caching and response handling
- Pruned unused dependencies

### Modernization

- Migrated to bridgeless React Native
- Adopted Redux for state management
- Upgraded React Query from v3 to v5

### Build and process

- Moved builds to a Mac Mini and streamlined the scripts
- Cross-team coordination and documentation for banners and deploys
